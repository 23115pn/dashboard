# Matcha & Co Website

## Overview
Matcha & Co is a delightful online platform that offers a variety of matcha-based drinks and desserts, as well as merchandise. This project showcases the menu items in a user-friendly manner, allowing customers to explore and enjoy the unique flavors of matcha.

## Project Structure
The project consists of the following files:

- **index.html**: The homepage of the Matcha & Co website, featuring introductory content and links to other sections.
- **menu.html**: Displays the menu for Matcha & Co, including categories for drinks and desserts.
- **all.html**: A combined view of all menu items, showcasing both drinks and desserts.
- **drinks.html**: Lists the drink items available at Matcha & Co.
- **desserts.html**: Lists the dessert items available at Matcha & Co.
- **merch.html**: Showcases merchandise available for purchase.
- **menu.css**: Contains styles for the website, ensuring a consistent look and feel across all HTML pages.
- **js/main.js**: Contains JavaScript code for interactivity and dynamic content.
- **img/**: Directory containing images used throughout the website, such as product images and logos.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open the project in your preferred web browser.
3. Navigate through the various sections using the navigation bar.

## Purpose
The purpose of this website is to provide an engaging platform for customers to explore and purchase matcha-based products, enhancing their experience with this unique ingredient.
